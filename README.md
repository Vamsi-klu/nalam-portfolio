# Ramachandra Nalam — Portfolio

Dark, cinematic personal portfolio inspired by [gazijarin.com](https://www.gazijarin.com/), tailored for a Data Engineer brand.

## Stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Custom canvas pipeline particles

## Develop

```bash
cd nalam-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Purpose |
|---------|---------|
| `npm run dev` | Dev server |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run lint` | ESLint |

## Content

Edit `src/content/site.ts` for bio, experience, work, OSS, and builds.

## Deploy

Push to GitHub and import on Vercel. Point `nalamportfolio.dev` at the project.
